# DairyDirect Frontend

A React + Vite frontend for the DairyDirect e-commerce platform.

## Setup

### Prerequisites
- Node.js v16+
- npm or yarn

### Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Server runs on `http://localhost:5173`

## Build

```bash
npm run build
```

## Project Structure

```
frontend/
├── src/
│   ├── components/    # Reusable components
│   ├── pages/        # Page components
│   ├── services/     # API services
│   ├── hooks/        # Custom hooks
│   ├── config/       # Configuration
│   ├── App.jsx       # Root component
│   └── main.jsx      # Entry point
├── index.html
├── vite.config.js
└── package.json
```

## Key Features

- Product browsing
- User authentication (signup/login)
- Order management
- User profile management
- Responsive design

## Technologies

- React 18
- Vite
- React Router
- Axios
- CSS3
