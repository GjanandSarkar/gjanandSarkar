# DairyDirect Product Requirements Document ## Project Overview DairyDirect is a hyper-local dairy e-commerce platform based in Ahmedabad, India. It focuses on farm-to-door delivery of Fresh Milk, Paneer, Ghee, and Buttermilk. ## User Roles 1. **Customer (Primary):** Mobile-first experience for browsing, subscribing, and tracking orders. 2. **Admin/Operations (Secondary):** Desktop-first dashboard for managing orders, subscriptions, products, and analytics. ## Brand Identity & Design Language - **Vibe:** Clean, warm, trustworthy, premium local brand. - **Visuals:** Rounded corners (16px cards, 12px buttons), subtle shadows, cream backgrounds, leaf/milk drop illustrations. - **Typography:** Inter (Bold/Semibold for headings, Regular/Medium for body). ## Color System - **Primary Green (#6e975c):** Main CTAs, active states, price text. - **Mint Accent (#a0cdaf):** Secondary highlights, success states, badges. - **Clay Brown (#ba7749):** Warnings, secondary buttons, promotional banners. - **Sand Beige (#e1d1b3):** Dividers, inactive states, input borders. - **Cream Background (#fafaf3):** Page backgrounds, card surfaces. - **Pure White (#ffffff):** Modals, inputs, nav bars. - **Dark Text (#2a2a2a):** Headings and body. - **Muted Text (#6b7280):** Labels and captions. ## Screen Inventory ### Customer App (18 Screens) C-01 to C-18 covering Splash, Onboarding, Login, Home, Browse, Detail, Cart, Checkout, Order History, Tracking, and Subscriptions. ### Admin Panel (11 Screens) A-01 to A-11 covering Dashboard, Order Management, Subscriptions, Products, Complaints, Delivery, and Analytics. ### Popups & Overlays (12) P-01 to P-12 for OTP, Cart, Address, Payments, etc. ## Responsive Strategy - **Mobile (375px):** Primary target. Single column, bottom nav, bottom sheets. - **Desktop (1280px):** Secondary. Sidebar navigation, grid layouts, centered modals.
